# Geographic exclusions from signed tile phases

A phase bit specifies which of the two colors touches the starting corner of a tile in the region coloring induced by a Gold loop. Flipping every color preserves all matches. Fixing a phase leaves the placement and rotation of every tile free.

For an original-board query with signed pins or required physical bonds, the ordinary `r30_gold.py embed` command checks whether the restrictions imply a known geographic impossibility. Its JSON input accepts a `pins` object mapping physical tile indices to 0 or 1. Tile-side inventories and required bonds can establish relative signs even when the input omits every phase bit. By default, unresolved queries continue with the ordinary model. Use `--phase-anchors rules` to post the verified exclusions in CP-SAT as well, or `--phase-anchors off` to reproduce the independent comparison.

The shipped results bind to the raw signed tile sides and the complete geographic mesh. A fresh process can use them with zero anchor probes. A changed rule needs a new geographic check. A completely different 160-tile control admits the exact signed phase that the original puzzle forbids. The default, explicit-rule and independent modes each returned its validated 240-edge, single-loop board. [Original donor and changed-artwork controls](R35_ANCHOR_BONDS.json)

The two shipped exclusions use 21 and 18 of the 160 signs. SAT unit propagation independently rejected every one of 480 placements of the selected anchor for each exclusion. They applied to 19 and 43 of the 54 nearby phases of their respective donors. In those sets, 7 and 20 covered phases respectively passed both earlier Euler and physical matching tests. In a separate panel of 105 phases neither short rule applied. Directly probing five scarce tiles rejected 48 on that panel, all already ruled out by at least one earlier test. These measurements support reusing the rules for related signed queries. [Paired tests](R35_HELDOUT_PHASE_ANCHORS.json)

For new phases, `--phase-anchors roots` tests the placements of scarce tiles first. `--phase-anchors shared` also removes poses excluded in every surviving branch of a completed split. Each policy uses verified board rotations only when the domains preserve them. The independent enumeration checked 768 pruning calls, complementary sign assignments and positive Gold layouts. [Independent audit](ROUND35_PHASE_BOARD_AUDIT.md)

A complete fixed-phase search can also use signed poses directly. For the third original donor, testing seven anchor tiles first removed 12,291 poses, reducing the native solve from 472,912 to 299,387 decisions and from 64,935 to 33,433 conflicts. The prefilter used 4,183 root probes. Both native runs found the phase infeasible. A separate solver produced a proof on the complete unreduced placement formula. An independent checker verified it in 526,397,865 resolution steps. This excludes the phase and its global color complement anywhere on the original mesh. Across seven original physical sewings and four shuffled bond orders each, the checked prefixes first excluded the sewing after 128 or 136 of its 240 named bonds on an eight-bond sampling interval. The public comparison supplied no phase pins. All seven default queries finished with zero CP calls, including six cases where the independent five-second run remained undecided. The harder fixed phase also yields two shorter restrictions. Fixing either verified set of 48 or 49 tile signs leaves 22 assignments consistent with the exact signed inventories in the recorded color convention. Physical pairing or geographic checks exclude each one. The two sets can answer different partial queries. In the paired public tests, the old default took 161,001 to 197,141 CP branches across four five-second runs and returned undecided each time. The new default refuted each query before building CP-SAT, on both Python 3.12 and 3.15. A neighboring query made by withholding one sign from each set and color convention still passed the precheck.
