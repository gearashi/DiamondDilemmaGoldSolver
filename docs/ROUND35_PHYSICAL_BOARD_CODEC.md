# Independent physical board checkpoint transfer

The standalone codec transports five 32-bit physical occupancy masks, five original used-tile words and packed int16 cell values in physical cell order for each selected lane. The caller's depths reserve output space. Undersized reservations request the existing raw capture. A larger reservation is safe. Firsts, shifts, cursor values, tile order and the host pool do not enter the transport. Each accepted packet preserves negative cell values other than the empty sentinel, duplicate tiles and inconsistent used words so independent checkpoint validation can reject a damaged payload.

The CUDA, Vulkan and D3D12 controls compared original board and used bytes on 144 static/dynamic cases across both host decoders. Each case used three warm samples. Widths were 128, 2,048, 128 spread across 2,048 lanes, and 32,768, with zero, four and another 64 nodes per lane. All accepted output matched direct native copies. Synthetic controls cover every occupancy bit, arbitrary signed cell values, an extra native used word bit, stale host metadata, odd and even packet widths, undersized reservations and raw fallback. A separate unsynchronized-input control lowered a live lane's supplied depth without changing device state. Direct-frame and standalone physical packets declined. The native and proof frame reconstructions returned different board bytes under this deliberately broken premise. Synchronized original captures matched the native arrays in all three APIs.

At 32,768 lanes the physical read was 1,558,396 to 2,765,052 bytes. The raw transfer was 11,141,120 bytes on CUDA and 21,626,880 on WebGPU. No persistent full-board GPU mirror is needed. The NumPy decoder's 32,768-lane host cost ranged from 32.88 to 88.81 ms. Optional native unpack reduced that interval to 2.39 to 5.39 ms. The full compiled transfer on Vulkan took 7.10 to 10.35 ms compared with 21.82 to 27.42 ms for raw. D3D12 took 6.77 to 10.22 ms compared with 19.48 to 23.88 ms. CUDA's raw path was faster in all 24 tested cases. Small WebGPU cases also favored raw in several configurations. These are synchronized board/used captures on one Windows GPU, separate from complete save time.

`PhysicalBoardCodec(gpu)` selects the validated optional decoder produced by `python build_native.py` and falls back to NumPy when unavailable. `PhysicalBoardCodec(gpu,'numpy')` forces the reference decoder. The loader checks ABI version, local platform and machine, the exact expected filename and both C source and binary hashes. The ordinary archive format remains the full board and used arrays. The benchmark command `python -m benchmarks.bench_r35_board_codec --help` lists its original-data, backend, shape and explicit decoder controls. Reproducing the rejected frame method requires its archived module via the optional --frame-control argument. The exact sample medians are in `docs/R35_PHYSICAL_BOARD_CODEC.json`.
