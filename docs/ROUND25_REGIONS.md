# Round 25 regional reasoning work

The stages below remain opt-in. Exact finite tests establish their stated scope; they do not solve the original Gold puzzle or imply a universal runtime improvement. Development counts will be superseded by frozen-source release validation.

## 14. Reversible exact regional DAG restriction — retained

`incremental_regions` compiles selected actual puzzle regions into a complete labelled DAG. A compiled envelope is reused only when every outside domain is identical and every inside domain remains a subset of its original value. The DAG retains all cell histories, physical inventories, exposed seam masks, strand pairings and cycle counts. Narrowing or undo updates counts from changed levels toward their ancestors. Previously returned views hold immutable state and remain valid after later sibling queries. Changes outside the region or widening beyond its envelope require another compiler query.

Integration is in `RegionalResearchPruner`: at most eight selected cells with at most eight choices each use this stage, under the existing 4,096-state / 50,000-transition bounds. These are optimistic regional subproblems on the original board, not a whole-board completeness claim. Interrupted compilers continue in memory; incomplete/capped relations never narrow domains. Disk continuation is proposal 15.

The finite seven-cell, 5,040-history relation was queried in 15 narrowing/undo contexts. Cold compilation used 1,479 states and 10,206 transitions; reuse compiled 128 states and 889 transitions once, then updated 14 nodes using 98 edge checks. Including initial reverse-index construction and support-view scans, counted enumeration/edge work was 15,141 versus 6,412. The reused path additionally copied 1,792 node-count entries and performed 15 source-binding comparisons; these are reported separately and are not free. No elapsed-time claim is made.

Six focused tests cover 100 complete domain contexts against independent exhaustive Gold/edge solutions, partial regions with changed outside assumptions, overlap joins, immutable old views, 34 interruption boundaries, malformed masks, caps, semantic source changes, the actual public DFS/ResearchPruner route, and a 160-cell planted Gold witness with repeated regional reuse. Twenty-two existing regional reasoning tests also passed. Reproduce finite counts with `python -B benchmark_regions_round25.py`.

The chosen policy retains four completed envelopes and four live compiler queries. It does not promise to eliminate every repeated allocation or to preserve those caches across a process restart.

## 15. Durable unfinished regional compilation - retained

`durable_regions` implies `incremental_regions`. The compiler uses explicit frames for entry, candidate transitions and pending children, plus completed memo states, terminal signatures and exact DAG nodes. Successful cooperative Stop boundaries can save this state to the application's configured regional cache directory; fresh processes restore the exact query and continue without revisiting completed transitions. Complete relations are the only source of domain reductions. A capped cursor remains unknown, including after restart. Without a configured directory the bounded compiler still works in memory and reports that disk persistence is unavailable.

Identity includes exact puzzle geometry and strand pairings, objective, all domains, regional cells, work limits, schema and producer source hashes. JSON checksums detect damaged files; strict numeric, table, graph-level, stack and accounting checks reject malformed records. Loads that fail these checks restart the optional computation. Writes are atomic, so concurrent processes can replace a record with either complete valid cursor state; an older writer can cause repeated work but cannot remove pending branches. Entry admission is bounded to 16 local files and each file to 16 MiB; concurrent admissions may briefly exceed the entry target. Disk errors leave solving available without that save.

This is a **trusted local computation cache**, following the existing regional-table cache model. Hashes and structural checks do not independently prove that a saved table contains every legal branch. No portable frontier or external proof import accepts these cursor payloads. Independent mathematical completeness certificates are proposal 25. Unexpected errors occurring inside a compiler transition mark that in-memory cursor unusable, preventing a half-executed transition from being saved or resumed.

The seven-cell restart discriminator interrupted three processes after 200 deterministic work ticks each, then finished the relation. Rebuilding from scratch attempted 1,303 transitions; durable continuation attempted the same 889 transitions as an uninterrupted compiler, with zero repeated completed transitions and the same 5,040 histories. Four writes serialized 247,901 bytes in total, and three loads performed JSON/source/shape checks. Those overheads are additional work. This is not an elapsed-time claim; an abrupt crash can repeat work since the last successful save. In-process saves occur on cooperative interruption, completion, or after 4,096 compiler ticks.

Nine focused tests passed: all work-tick restart boundaries for both edge and Gold relations; exact agreement with the previous compiler; new-process stage continuation; completed-cache reuse; corrupt, malformed and changed-source/cap rejection; storage errors and cached unknowns; two concurrent spawned writers; unexpected mid-transition faults; actual written-byte bounds and strict pending-child/cap invariants; and the actual public DFS route with `extended_regions` disabled. Reproduce the finite record with `python -B benchmark_regions_round25.py --candidate 15 --output <report.json>`.
