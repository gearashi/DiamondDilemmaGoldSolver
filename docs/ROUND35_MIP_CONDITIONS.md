## Global physical pairing with variable tile signs

Use `--physical-pairing` with `integer-bound` to choose every physical side’s mate and measure the actual named bonds lost. A multi-loop result is a valid physical pairing. The output lists all 240 mates and the independently traced circuit lengths. A single-loop result also undergoes geographic validation. Python 3.12 with OR-Tools can search cold. Python 3.15 can replay bundled feasible pairings after locally checking every mate. [Full paired controls](R35_PAIR_PROJECTION.json)

The 46 blank sides permit 1,034 physical pairs. One same-tile pair is illegal, and the 22 named reference joins form a matching. After keeping the selected named joins, split the remaining sides by signed color. Every lost named join remains forbidden. For each even residual size of at least four, a matching exists when the forbidden edges are a matching plus at most one extra edge. For four vertices the disjoint forbidden matching can meet only one of the three full pairings. An extra forbidden edge can meet one other. For larger even sets each vertex has at most two forbidden partners, so a permitted pair can be removed and the four-vertex argument completes an induction. At size two the sole pair must be allowed. Empty sets need no pair.

The integer model encodes these counts exactly, falls back to explicit choices for other forbidden graphs, and reconstructs an actual legal completion. Blank choices preserve the physical strand circuits. A different sewing can change the mesh embedding, so every reported single loop gets its own geographic test. An optional flow formulation relaxes auxiliary choices to continuous values only in families that are bipartite once the signed tile phases are fixed. An augmenting-path search reconstructs an integral pairing while preserving every selected and excluded named mate. Self-reciprocal even families retain their integer choices.
