# Compiling labelled signed-inventory queries

For conditional phase projection, combine fixed offsets, contract any supplied equal/opposite phase relations, group interchangeable internal increments and keep tagged boundary variables separate. The elimination order minimizes live balance coordinates. The split compiler chooses the smallest shared-coordinate interface among balanced cuts of that order and joins exact residual sums, parity and Euler at the separator. Private coordinates retire after their final contribution. Both methods return UNKNOWN without partial patterns when a state or transition allowance is reached. Optional multiplicities count labelled internal assignments, including reversed and zero increments.

At the same 10,000-state cap, the old order completed seven of sixteen cases sampled from two independently obtained original 160-tile sewings. One-pass completed nine and splitting completed ten. All sixteen reference pattern sets were independently recovered by native CP under each labelled boundary assignment. With sixty phases free, split completed both scopes using 19,108 and 9,666 transitions. On one of these, one-pass needed 50,288 transitions and the old order capped. On the other, both alternatives capped. The original 160-free queries remained open under the cap, with 38 and 40 shared coordinates. Their internal signatures had only two interchangeable components. The reduction on this drawing mainly came from the elimination order and exact separator.

Nineteen historical signed loss assumptions were exercised with the one-pass compiler. One closed within 10,000 states and eighteen remained unresolved. Keep the dedicated integer pattern filter on that path. Four hundred exhaustive finite controls checked labelled multiplicities for both compilers, mixed parity, pinned/complemented phases, repeated signatures and arbitrary boundaries. The positive saturation/cap fixtures also check that incomplete patterns cannot enter the cache.

The existing phase-query CLI now uses grouped compilation and switches to the split order at twenty groups. A query can select `phase_order` of `single`, `split` or `legacy` for comparison. Cache hits and restrictions of a completed boundary retain their previous meaning.
