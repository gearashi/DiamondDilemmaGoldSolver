# Scoped logic search in round 28

The **Easy remainder** DFS option now checks residuals with more than eight unfixed cells when every cell has at most two physical placements. Each implication graph enforces physical tile uniqueness and all seams. A Gold search independently checks connectivity, then partitions any remaining search on the first changed member of a closed proper loop. Stop or a work limit returns control to the owning DFS frame. The Python 3.15 profile supports this path.

The other methods are available through `python r28_logic.py METHOD --data data/tiles.json --domains domains.json`. A domains file contains one array of legal rotation codes per cell. Use the full Python 3.12 environment for OR-Tools and PySAT methods. The cut and core methods optimize matching seams. Only an independently validated single loop on a complete physical board establishes Gold.
