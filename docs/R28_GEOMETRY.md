# Round 28 physical and geographic search

The saved 207-edge board with 52 components contains a set of **15 physical seams that cannot coexist in any Gold board**. The test needs the tile identities, side masks and local segment drawings. It does not fix any tile to a cell. A different arrangement can keep up to 14 of those seams. Testing each single deletion from the 15 restored feasibility in the signed-inventory relaxation. The additional Euler constraint gave the same core. The complete board remains an open search. With the other 159 cells fixed to that saved board and all three rotations admitted at cell zero, the checked core prunes placement 437 and leaves placements 435 and 436 for other deductions.

The JSON evidence records the 15 physical-side pairs under `original.signed_core.bonds`. A physical-side number is three times the zero-based tile ID plus its zero-based side. The probe considered 100 of the saved board's 207 already-matched seams, shrank an assumption core, and rebuilt the final infeasibility test using only the 15 seams. This deduction applies to edge-perfect Gold search. A soft search aiming for 208 seams can keep all 15.

## Commands

`r28_geometry.py` exposes the narrow models independently. The CP modes use the optional OR-Tools search dependencies. Place the argument JSON outside the source tree if you wish to keep saved layouts private.

```shell
python r28_geometry.py phase --input phase-request.json
python r28_geometry.py core --input signed-bonds.json
python r28_geometry.py dual --input restricted-domains.json
python r28_geometry.py regions --input partition.json --method orbit
python r28_geometry.py regions --input partition.json --method paged --checkpoint join-progress.json --max-work 10000
python -m unittest test_r28_geometry -v
python -m benchmarks.bench_r28_geo --tiles data/tiles.json --incumbent runtime/best.json
```

A phase request may include `probe_tiles`, `probe_bonds`, a `pins` map and `euler`. A core request has a `bonds` array of physical side pairs. Supplying restricted `domains` in the same request runs the checked physical nogood as a placement filter, returning the surviving domains. A partition file has `regions` (arrays of zero-based cell IDs) and optional `domains` (allowed orientation codes for each cell). The phase and packing commands answer feasibility in their respective relaxations. Any published full geographic witness passes the existing independent validator. Resource-limited searches report unknown or incomplete. Measured original outcomes use the saved 207-edge, 52-component board and can differ for other incumbents.
