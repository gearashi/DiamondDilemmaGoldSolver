The exported table describes each labelled compulsory component pose implied by a candidate at a specific cell and rotation. CUDA and WGSL check the current board, used tiles, neighbouring compulsory anchors and already occupied external seams. The table added 7,861 immutable 32-bit words (31,444 bytes) on the original drawing. Undo uses the existing placement stack. Large generic components fall back to the required direct mates within the table budget.

On the eight original compulsory bonds, both directions of each pair were exercised. Sixteen lanes with the future tile already installed remotely and sixteen with an incompatible external seam survived the old guard for 919 and 922 candidate attempts respectively. The new guard closed all 32 with zero attempts on NVIDIA CUDA, Vulkan and default-FXC D3D12. All sixteen permitted controls remained active. The ordinary edge objective used zero table words and took 951 attempts. An extra inverse lookup on sixteen unrelated later candidates saved zero placement attempts after the existing candidate bucket guard and was left out.

Sixteen child prefixes above the saved floor in each ordering unwound without a new candidate attempt, preserving parent cursor, shift, first choice and RNG. The dynamic fixture's actual child rank was one while its static rank was forty. A 40-test enabled native regression suite passed, covering finite exhaustive solution/frontier controls, single/multiple loops, continuation and resize.
