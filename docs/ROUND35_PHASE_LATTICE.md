# Signed phase-column divisibility before native inventory search

The phase checker contracts XOR-linked tile phases into optionally complemented binary components. It accumulates the pinned contributions and builds a sparse integer column for flipping each free component. Self-reciprocal parity rows receive a slack column of two. An Euler check prices each allowed final Euler target separately. Coordinate gcd tests precede an integer column basis. A rejecting result must supply a sparse dual functional that independently annihilates every generator modulo its reported divisor and separates the target. A zero modulus denotes an exact equality. An operation or bit budget returns an unresolved result.

None of the 89 historical full and partial assumption queries failed the binary parity baseline. The lattice admitted every signed inventory balance query. Native CP rejected exactly four: the three full R34 integer arrivals and the original minimized R33 disagreement core. The other 85 were feasible. With Euler included, the lattice admitted 83, including all 11 native rejections, and reached its arithmetic budget on six independently feasible queries. Consequently this extra test would avoid zero native integer decisions on these arrivals. Leave it off the production refinement path. The newer verified finite integer-pattern method remains applicable to its own release-bound scopes.

Synthetic controls show why integer-column membership can distinguish more than GF(2): a determinant-three two-column matrix admits every residue modulo two yet rejects the supplied target modulo three. Tests also exercise a single coordinate divisible by four, parity slack, complemented/pinned choices and all binary assignments on 300 small random instances. A new original residual carrying a checked nontrivial lattice obstruction after binary parity would justify reopening the search policy.
