# Minimum geographic changes from the 207 board

Every Gold board differs from the published 207-matched-edge arrangement in **at least 93 of its 160 oriented cell assignments**. Rotating the same triangle in its original cell counts as one change. Replacing it with another triangle also counts as one change, regardless of the replacement's orientation. The 93-cell relaxed hitting assignment still contains a geographic contradiction.

## Where the lower bound comes from

The repair master chooses cells to change. Each row lists a set of original poses that cannot all survive in a single-loop Gold solution. Any Gold repair must change at least one cell in every row.

| Necessary conditions on the original seed | Proved minimum changes |
| --- | ---: |
| Endpoints of the 33 mismatched seams | 27 |
| Add proper circuits | 28 |
| Project checked geographic and physical reference obligations | 29 |
| Include mandatory neighbor poses and donor ownership | 30 |
| Joint neighbor placement support | 58 |
| Single-anchor geographic propagation, full domain width | 71 |
| Pairs up to two cells apart | 83 |
| Pairs up to three cells apart | 88 |
| Pairs up to six cells apart, domain width 128 | 89 |
| Add 88 contradictions extracted from proposed changes | **93** |

The all-distance pair screen reached the same 89 as radius six. Checking the broad 331 signed departure groups, 194 geographic groups and 985 edge-contact groups raised the local corpus from 99 to 190 rows before the joint geographic pass and produced the same bound of 30. Generic repairs use width 64 and radius two. The verified original poses can be reused wherever the new seed agrees. Fixed or restricted cells can make a scope infeasible before an oracle query. A seed differing by one orientation from the original receives a bound of at least 92.

The independent geographic encoder enumerated 3,060 reciprocal dart pairs from the raw endpoints. It removed 21 pairs that seal a proper circuit and three more that prevent a perfect physical matching. It separately checked all eight compulsory mates. Its 230,080-variable, 690,240-clause geographic formula refuted 3,800 original rows by unit propagation. The independent circuit checker confirmed the remaining four. All 120 adaptive additions replayed against the geographic formula.

The original 3,804 rows admit an 89-cell relaxed assignment. DRAT-trim verified the 88-change refutation in 2,788,450 resolution steps. With 88 more rows a fully checked 93-cell hitting assignment exists, and the cap92 formula regenerated byte-for-byte. Its external DRAT checker used 13,977,119 resolution steps. The remaining 32 rows exclude that 93-cell assignment. One-, two- and three-cell exchanges from it recovered no equally sized hitting assignment. The bounded cap93 search on all 3,924 rows used 120 seconds across an interruption and retry and remained unresolved. The runtime includes all independently checked rows and tests any proposed master answer against the active obligations.

These are charged native branches from every CP-SAT call in the public repair, including unfinished masters. Each solver used one worker, a 128-conflict parameter and a limit of 3 deterministic seconds. In the original column comparison the first two configurations passed their prepared candidate straight to the Gold oracle. The third saw a known contradiction in that candidate and moved directly to the harder hitting-set master. In additional 52-second public slices, the all-120 master returned an unresolved scope on all three original seeds. An unresolved native master may repeat work after a process restart. The known contradiction rows and verified floor apply immediately on reopen.

For three held-out four-tile seeds every variant matched the true Gold distances 1, 3 and 4. The actual Gold queries used 100, 100 and 112 branches respectively. Independent enumeration checked legal pose cuts against every Gold solution across all 1,944 oriented tetrahedral seeds. Parallel seams, invalid source data, changed domains, fixed conflicts, runtime cancellation and retained-state reuse have separate controls. The solver persists derived rows separately from earned native failures. An existing pending query runs before the next master takes the new clauses.

## Reproduction and continued search

After the normal tile-data preparation, use the Python environment with OR-Tools and python-sat. The two published proof archives include the DRAT files, CNFs, manifests, and checker logs. Each invocation below should run alongside the corresponding archive's extracted proof.

```sh
python bench_r35_repair_seeds.py --tiles data/tiles.json --catalog --write-cap88 cap88.cnf --output base-replay.json
drat-trim cap88.cnf cap88.drat
python bench_r35_repair_refinement.py --tiles data/tiles.json --write-cnf cap92.cnf --output refined-replay.json
drat-trim cap92.cnf cap92.drat
```

To examine a different candidate without changing solver evidence, supply a JSON list of proposed changed cell indices to `bench_r35_repair_refinement.py --selection cells.json --output checked-cuts.json`. The default extracts up to 32 independently checked local conflicts. The original screen ended at the first unresolved cap, inside a single 510-second adaptive block. Additional candidates now belong to the ongoing search over that same mechanism.

For unrestricted single-loop Gold search on Windows use `.\StartSolver.cmd -Algorithm dfs -Unlimited`. Linux and macOS use `bash StartSolver.sh --algorithm dfs --unlimited`. Use the scored-board repair mode when the specific objective is minimum change from a supplied board. The best scored geographic board in these tests remained 207/240.

The measured controls and file identities are in [the result record](R35_REPAIR_DISTANCE.json), [the antecedent proof receipt](R35_REPAIR_DISTANCE_PROOF.json) and [the refined proof receipt](R35_REFINED_REPAIR_PROOF.json).
