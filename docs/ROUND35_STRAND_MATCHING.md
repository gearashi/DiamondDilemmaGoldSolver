# Strand matching on contracted paths

A cycle on an even number of strand paths contains a perfect matching. From an odd cycle, deleting any one path leaves a perfect matching. The benchmark contracts every required open path and constructs possible adjacencies only from still-exposed endpoints. Proper closed loops use the existing distinct rejection. One and two remaining path components bypass the simple-graph test because two different physical joins can connect the same two components.

The benchmark builds maximum matchings with odd-blossom contraction and finds all even-reachable vertices from an exposed root. Each proposed negative must also supply an independently checked set whose deletion leaves more odd components than deleted vertices, on the even graph or after a single specified vertex deletion. Work exhaustion produces an undecided result.

The actual root has 365 segments and 345 contracted components. It passed. Every one of the 1,994 optional nonblank root mates passed. The eight other nonblank mates were already required. Blank joins do not touch the strand graph. On 60 fixed-bond scopes, published matching support already closed 19. All 41 surviving scopes and their 4,474 single-mate probes on sides with up to three partners passed. Among 21 held-out geographic scopes, old matching support closed 20. The last scope and all 122 sparse probes passed. In all 6,590 conditional probes there was no new closure and no work-limit result. Leave this check out of the production search.

The implementation is preserved as a reproducible research benchmark. Independent recursive perfect matching agrees on every labelled simple graph with three through six vertices and 2,100 additional seven- through nine-vertex graphs. The complete bipartite graphs with parts (3,4) and (3,5) pass the existing two-vertex separator test but fail the new matching conditions, with verifiable odd-component obstructions. Planted geographic single loops stay accepted through every prefix of three complete sewings. A completed split-control circuit is rejected by the pre-existing proper-loop condition. A new representative residual showing an odd-component barrier after actual side-matching and separator checks would justify reopening.
