# Round 29 Gold constraints and regional witness experiments

The endpoint and parity rules apply to an edge-perfect single loop. The unsigned geographic upper bound also applies to partial seam matching. All indices in input JSON are zero-based. A tile's sign selects one of the two colors of its planar regions and is independent of its three physical rotations.

| Workstream | Actual result and operating scope |
|---|---|
| 6. Endpoint groups and bundles | Every tile arc joins two canonical reciprocal endpoint types. Any Gold tour projects to a connected multigraph. For each connected type subset, compile phase conditions that prevent crossing while forcing an occupied arc on each side. Enumerate both color conventions, eliminate subsumed clauses, and propagate partial phase choices. Including all connected subsets of size at most two tested 801 subsets and kept 336 forbidden assignments. Extending to triples tested 7,628 subsets and kept 2,418. The previous signed/Euler relaxation admitted the five-pin assignment R50=0, R63=0, R78=0, B90=1, B127=1. The new pair cut rejects it and its complement. A twelve-pin assignment admitted by the old relaxation *with every pair cut* fails a triple cut. Both checked assignments are recorded in the results. An optimistic follow-up connects physical strand IDs through actual reciprocal side and slot candidates respecting pins and already chosen side pairs. Excluding candidates or imposing pins only removes prospective links. |
| 7. Reversible parity | Reduce the signed reciprocal equalities and self-reciprocal even-count constraints modulo two. The real inventory has rank 44. The 15-bond core from v1.9.0 follows by XOR using those bonds and just two physical inventory equations. This costs zero CP calls. A single bond prunes zero of 3,060 root options. Branches may add bond XORs or individual pins, read forced variables, extract the subset supporting a contradiction, project out internal phases, and roll back. Repeated boundary projection reuses its result after rollback. The existing signed seam probe now screens candidate bonds this way, and its minimal-core search can start from the parity explanation before exact CP verification. |
| 8. Ring inventories and refinements | Aggregate tile placement options by geographic half-side class and reciprocal mask while preserving physical piece counts. For Gold, include signed reciprocity, channel the colors of all exceptional mesh vertices to tile placements, and impose their Euler adjustment. The optional vertices refinement channels all vertex colors. For soft matching, each reciprocal pair contributes at most the smaller class count, or half the count for a self-reciprocal class. The encoded mesh has nine rings of sizes 1,5,10,15,20,15,10,5,1. The benchmark frees the first six cells of the saved 207 layout, allowing arbitrary permutations and rotations of their six pieces while fixing the other 154 orientations. Ring and face-sector relaxations both give upper 208. Adding a second landmark gives upper 207 and closes this residual. The same tightening occurred with two free cells. These results do not bound the full 160-cell optimum. The unrestricted root soft ring model returned unknown in a three-second pilot. |
| 9. Color-region capacity | Contract permanent seam intervals and all optimistic links outside a selected cell group. Each remaining placement can supply only a bounded number of independent region connections. Compare this capacity against the total contraction deficit and weighted color-specific requirements, respecting how many intervals a single selected placement can actually join. Both color-specific bounds accept the known planted Gold boards. On a ten-cell partial fixture the unrestricted optimistic graph survives. Removing cell 6 from that optimistic contraction leaves a two-link deficit while any placement supplies at most one. Exhaustive enumeration independently finds zero Gold boards. The residual dual search now closes this instance before asking CP for a completed board. It enables this prescreen for one to eight ambiguous cells. Wider bags and phase-pinned variants are available as explicit queries. |
| 14. Cut&Count | Tested two-region witness search carrying physical inventory, seam masks, consistent binary strand colors, and random placement weights. One strand has a fixed color. Every board with k loops contributes 2^(k−1) colorings, so any odd weight bucket has a connected witness. An XOR digest recovers isolated witnesses, with exact self-reduction available on a digest collision. Every returned board is independently validated. Ten- and forty-cell controls required 200–9,692 color transitions while the existing trie kept only two regional states. On the fixed 160-cell control Cut&Count exhausted a 150,000-work budget while the trie succeeded. Kept for benchmark reproduction and explicit experiments. It is excluded from automatic search. Zero parity or an interrupted run gives unknown. |

## Running the checks

The existing signed probe and residual dual solver incorporate the parity and capacity prescreens. Use the following commands for explicit residuals. Ring modes require OR-Tools. Full-board tile downloads and best/checkpoint files stay outside the source package.

```shell
python r29_gold.py phase --input phases.json --max-work 10000
python r29_gold.py rings --input residual.json --seconds 10
python r29_gold.py soft-rings --input residual.json --seconds 10
python r29_gold.py capacity --input residual.json --max-work 100
python r29_gold.py cut-witness --input residual.json --max-work 150000
python -m unittest test_r29_gold test_r28_geometry -v
python -m benchmarks.bench_r29_gold --tiles data/tiles.json
```

A phase request can provide a `pins` object mapping physical tile indices to 0/1, a `bonds` array of physical side pairs, `width` for connected type-subset size, and `boundary` for variables to keep in the parity projection. Use `"cp": false` for quick deductions only. With a feasible CP result the signed model has a phase assignment under that relaxation. It does not supply physical placements. Width two is a starting point. Width three costs more preprocessing and proved a strict extra rejection. The subset budget controls discovery and never turns an incomplete scan into a proof of feasibility.

For geography and capacity, `domains` is one array of allowed orientation codes per cell. Ring modes accept `"detail": "rings"`, `"sectors"`, `"landmark"`, or `"vertices"`. In Gold ring mode `pins` refers to **mesh vertex** colors. In capacity mode `pins` refers to **physical tile** phases. The soft bound uses unsigned inventories. For capacity, use `bags` for explicit lists of separator cells, or `width` to determine the largest group searched. Cut&Count accepts a proper `inside` region, an integer `seed`, and a positive `trials` count.

The checked benchmark stores its reference placement codes and problem fingerprint for reproduction after a user's live best changes. [Recorded results](R29_GOLD_RESULTS.json)
