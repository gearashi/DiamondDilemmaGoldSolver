# Sharing checked geographic conflicts

A geographic core contains named pairs of physical sides. Its producer's description is a hint. The receiving engine checks that the pairs are compatible, then either verifies positive genus on the oriented sphere or proves that their rigid components cannot be placed together. A complete footprint rejection belongs to the verified domain or a narrower domain. Positive genus is independent of the cell domains. A wider sibling, new drawing or interrupted proof cannot inherit an unverified negative. Checked cores can exclude supersets, and at most 128 certificates remain in the per-puzzle cache.

The five-bond mixed-turn obstruction and the 14-, 21-, 27- and 94-bond obstructions shared by actual alternating-sewing families all passed this independent receiver. The old physical parity/proper-loop certificate checker rejected none of these combinations. In the geographic master, four exact conjunctions without hints reached 169,810 total branches across four bounded calls and remained open. Given the same hints, the previous geographic implementation closed all four in presolve, using four native calls and zero branches. The new receiver closed the same four before constructing a native model. Five initial proof checks served 44 repeat uses in the recorded experiment.

SAT, CP, CP-SAT, its circuit form and DFS accept independently checked geographic units. Each of four held-out legal-domain scopes lost one placement while exhaustive enumeration preserved all ten labelled Gold and edge-perfect boards. Edge-only search can accept a checked geometric obstruction. It does not inherit signed or proper-loop exclusions. The validators cover a valid reported sewing, malformed evidence, unavailable budget, a narrowed-only conflict and a widened sibling.

The installed classic checkpoint's 131,072 lanes (128,854 active, maximum depth 89) contained 128 instances of four out of five mixed-cycle bonds. Every such lane had already placed both owners of the last seam. None of the other four cores reached a unit, so this native checkpoint offered zero candidate eliminations. Two installed CPU search stacks had zero units in 25 and 26 frames. Keep the checked CPU transport available when a producer supplies a core. The native lanes provide no evidence for broadcasting these stored cores to every GPU search.
