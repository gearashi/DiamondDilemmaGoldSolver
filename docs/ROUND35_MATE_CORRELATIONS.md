# Conditional perfect-match partners

Within one reciprocal side class, condition a complete matching on a named seam and compute which other seams every matching needs and which no matching can contain. The subset recursion shares residual masks across all head pairs and returns no claims after its work allowance. Dense large classes are skipped. CP can post equality, implication and nonincident mutual exclusion on represented mate literals. Known tile phases narrow classes before compilation. A signed contradiction arising only after necessary partners are added can exclude the initiating mate. Use `python r30_gold.py matching --mate-correlations` or `embed --mate-correlations`; `--mate-correlations signed` posts only independently derived signed exclusions.
